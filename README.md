# 🏆 Vitrina de Cartas Coleccionables de Deportes

Catálogo público e interactivo de cartas coleccionables de deportes (**Básquetbol / NBA**, **Fútbol Mundial y Chileno**, **Béisbol / MLB**, **Fútbol Americano / NFL**, **Fórmula 1 / Motor**, **Tenis**, **UFC / Wrestling** y más), detallando para cada pieza:

- **Jugador / Protagonista y Equipo**
- **Marca / Set y Número de Carta** (*Upper Deck, Panini Prizm, Topps Chrome, Fleer, SkyBox, Salo, etc.*)
- **Año de lanzamiento y Época coleccionable** (*Vintage Pre-1980, Años 80, Junk Wax / Años 90, Años 2000, Era Moderna / Prizm*)
- **Rareza** (*Base, Rookie Card RC, Insert, Refractor / Prizm / Holo, Numerada / Serializada, Autógrafo / Memorabilia, Sticker Histórico*)
- **Estado de conservación y autenticidad**
- **Valor estimado de mercado (USD / CLP) y precio de venta sugerido en Chile (CLP)**
